# 图谱三视图

> **学习目标**：用「图谱」页的三种视图看懂对象与实例的关系网络——本体视图（骨架）、类树（层级）、知识图谱（实例网络）。

![图谱页](assets/graph-page.png)
*图谱页：顶部三视图切换（本体视图/类树/知识图谱），下方画布，上方为自然语言查询入口*

## 1. 三个视图看什么

| 视图 | 看什么 | 典型用法 |
|---|---|---|
| **本体视图（Schema）** | 对象类型 + 属性 + 关系的骨架（TBox） | 建模后核对结构是否完整 |
| **类树（Tree）** | 对象类型的层级树，可折叠 | 浏览对象体系，展开看已入库实例数 |
| **知识图谱（Knowledge）** | 实例之间的关系网络（TBox+ABox 合并） | 点选实体看属性与出/入向血缘 |

## 2. 点选实体看详情

- 知识图谱视图中**点选任意实体** → 弹出详情面板：
  - 全部属性值；
  - **出向血缘**（它引用了谁）与**入向血缘**（谁引用了它）；
- 这是追溯"某条数据被谁依赖"的最快路径。

## 3. 视图选择口诀

- 问"结构对不对" → 本体视图；
- 问"体系怎么分" → 类树；
- 问"数据怎么连" → 知识图谱。

## ⚠️ 常见坑

- 知识图谱是**只读**视图，不能在这里改数据（改数据 = 重导入，见第 10 章）；
- 节点很多时先按对象筛选/搜索定位，再展开邻居，别一上来全展开。
