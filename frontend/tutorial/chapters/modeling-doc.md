# 建模：文档逆向

> **学习目标**：上传一份业务文档（PRD/需求/Word/Excel/PDF/文本），平台**异步解析**出本体草稿——适合"需求已经写成文档，但不想逐字段手敲"的场景。

![文档逆向](assets/modeling-doc.png)
*建模页「文档逆向」子页签：选择文件 → 开始解析（支持 txt/md/docx/xlsx/pdf）*

## 1. 入口

- 建模页 → 编辑区 → 子页签 **「文档逆向」**。
- 点「选择文件」，支持 **`.txt` / `.md` / `.docx` / `.xlsx` / `.pdf`**。
- 点 **「开始解析」**。

## 2. 异步解析（job 机制）

- 上传后后端创建一个**解析任务（job）**，前端轮询任务进度，页面显示解析中状态；
- 解析完成 → 生成**本体草稿**并自动跳回编辑器（表单视图），流程与 AI 生成一致：
  **人工检查修正 → 保存草稿 → 校验发布**。

## 3. 什么文档效果好

- 文档里要有**实体、字段、关系**的描述（PRD、数据字典、需求说明书最好）；
- 结构清晰（标题分节、字段表格）的文档，解析出的对象/属性质量明显更高；
- 纯叙述、没有字段清单的文档，解析结果往往只有骨架，仍需大量手工补充。

## ⚠️ 常见坑

- **解析需要时间**：长文档/大文件别关页面；任务在后台跑，刷新会丢进度提示（任务本身不丢，重新进编辑区可看状态）；
- **扫描件 PDF 不行**：PDF 必须是**可提取文本**的，图片型扫描件解析不到内容；
- **xlsx 按 sheet 解析**：一个 sheet 的内容可能被理解为不同对象；
- 解析结果同样是**草稿**——必须人工检查 + 走校验发布门（第 8 章）。
