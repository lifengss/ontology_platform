# 查看视图

> 学习目标：能在图谱 / 实例 / 推理 / 业务动作视图中查看数据，理解各视图的定位与差异。

## 1. 图谱

1. 左侧导航 → **图谱**
2. 左上**选择本体**下拉选目标本体
3. 三个视图 tab 切换：

| 视图 | 看什么 |
|---|---|
| **本体视图** | 本体的对象 / 属性 / 关系结构（节点 = 对象，边 = 关系，节点大小按度数） |
| **类树** | 对象类继承树（按「上级对象 / 父类」展开） |
| **知识图谱** | 实例 + 本体的融合视图（实例按对象类型着色，上方可设实例上限） |

- 图谱上方有**自然语言查询**输入框：如「成本模型中所有已发布对象的实例数量」，点查询查看结果
- 工具栏**适应画布**可一键恢复视角；画布支持拖拽 / 缩放 / 点节点查看属性

![图谱页：三视图与自然语言查询](assets/graph-page.png "图谱页：本体视图/类树/知识图谱 tab、自然语言查询输入框")

## 2. 实例列表

1. **实例导入**页右侧的**「全部实例」**tab（带实例数徽标）
2. 可按**对象**筛选、按实例 ID / 属性值搜索
3. 列表逐条展示实例（JSON），点行内**详情**查看属性、**编辑**修改属性
4. 对象视图选中对象时，其**实例列表**卡片也展示该对象的实例（分页）

![实例列表](assets/instance-list.png "全部实例列表：对象筛选、搜索、逐条实例")

## 3. 推理与业务动作

- **推理**页：
  - **业务影响推理**——指定目标实例 + 变更属性（如单位成本 12.5 → 15），平台沿关系链推断受影响的下游实例（如「产品成本将上升」），结果展示在页面下方
  - **模式层推理**——基于本体结构（关系 / 基数）的推理
- **业务动作**页：定义可基于本体数据触发的外部系统写回动作（webhook / MCP 外部调用）。**当前平台为「只展示 · Dry Run 预览」，写回能力尚未开发**（后端已阻断），页面展示动作定义与触发条件，可 Dry Run 预览执行计划

> ⚠️ 高频坑：推理结果的「影响」是**语义级推断**，不是数值级精算。业务影响推理展示「哪些对象会受影响」及方向，精确数值需到业务系统核对。
