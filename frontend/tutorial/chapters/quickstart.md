# 快速开始：10 分钟跑通主线

> **学习目标**：不追求全，只跑通一次最小闭环——建一个小本体 → 发布 → 导一条实例 → 审核入库 → 在图谱里看到它。全程约 10 分钟，每步都有明确产物，细节功能到后续章节展开。

## 0. 前提

- 平台已启动：后端 `http://localhost:8000`，前端 `http://localhost:8123`（启动方式见仓库 `README.md`）。
- 浏览器打开 `http://localhost:8123/`，右上角「后端健康」显示绿色 ✓（含 Jena/Neo4j 依赖状态）。

![平台首页](assets/home.png)
*平台首页：左上标题，右上角显示当前部门/项目与后端健康状态*

## 1. 选对部门与项目

- 右上角两个下拉框选**部门 → 项目**。所有数据按项目隔离，后续每一步都在这个项目的上下文里。
- 没有项目就在「设置 → 项目」页先建一个。

> ⚠️ 未选项目时调接口会报 `403 NO_PROJECT`；列表类接口必须带 `project_id`。

## 2. 建一个最小本体（约 3 分钟）

1. 点左侧「建模」→ 右上「＋ 新建」。
2. 填本体名称（如 `客户订单`）、描述。
3. 加一个对象 `Customer`，再加一个属性 `customer_code`：类型 `string`、**必填**。
   第一个「必填 + string」属性会自动成为主键（🔑 徽标），不用手动指定。
4. 「保存为草稿」。

![表单建模](assets/modeling-form.png)
*建模页：左侧本体列表，右侧编辑区（表单建模子页签、对象/属性编辑）*

## 3. 发布本体（1 分钟）

- 选中刚建的本体 →「校验并发布」。
- 通过两道门（对象主键完整、无悬空关系引用）后状态变 **已发布**。未发布的本体不能导入实例。

![发布后的本体](assets/ontology-published.png)
*本体列表：状态徽标变为「已发布」*

## 4. 导入一条实例（3 分钟）

1. 左侧「实例导入」页 → 选中该本体。
2. 文件导入：上传一个 Excel/CSV（两列 `customer_code`、`customer_name`，一行数据）。
3. 点「预览」（不入库，只做校验）→ 无误后「生成候选」。
4. 候选区点「批准入库」→ 实例进入**已入库**。

> ⚠️ **导入 ≠ 入库**：预览生成的是「待审核」候选，必须审核批准才真正落库。这一步是平台的数据质量门。

## 5. 在图谱里看到它（2 分钟）

- 左侧「图谱」页 →「知识图谱」视图：能看到 `Customer` 节点与刚入库的实例。
- 想试试 AI？同页顶部「自然语言查询」输入框问一句「有哪些客户？」（需已在「设置」页配置 LLM，见第 17 章）。

![图谱三视图](assets/graph-page.png)
*图谱页：本体视图/类树/知识图谱三视图 + 自然语言查询入口*

## ✅ 跑通自检

- [ ] 本体状态 = 已发布（本体列表徽标）
- [ ] 实例列表能看到这条 `Customer` 实例
- [ ] 知识图谱视图中点选该实例能看到属性详情
- [ ] （可选）自然语言查询返回了该实例
