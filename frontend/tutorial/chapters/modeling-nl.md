# 建模：自然语言建模（AI 生成）

> **学习目标**：用一段自然语言描述业务场景，让 LLM 直接生成完整本体（对象 + 属性 + 关系），生成结果落为**草稿**，人工检查修正后走统一校验发布门。

![AI 生成](assets/modeling-ai.png)
*建模页「AI 生成」子页签：描述框 + 开始生成（生成结果为草稿，可编辑后发布）*

## 1. 入口

- 建模页 →「＋ 新建」（或点已有本体进编辑区）→ 顶部子页签切到 **「AI 生成」**。
- 输入框里用自然语言描述业务场景，例如：
  > 客户可以下多个订单，每个订单包含若干商品，商品有 SKU 和库存。
- 点 **「开始生成」**。

## 2. 生成过程

- 后端把描述 + 本体生成 Prompt 模板（「设置 → LLM」页可编辑）发给配置的 LLM；
- 返回的完整本体（名称/描述/对象/属性/关系）**自动填入编辑器**，状态为**草稿**；
- 此时可以切回「表单建模」子页签逐项检查修正：对象名、属性类型、必填、主键、关系基数。

## 3. 生成后必须人工检查（平台立场）

AI 生成**不等于**建模完成，草稿必须过人眼：

- 模型可能**臆造字段**或类型选错（金额给了 integer）；
- 主键可能缺失（没有「必填 + string」属性 → 第 8 章校验卡发布）；
- 关系基数可能不符合业务实际（1:N 还是 N:N）。

确认无误 → 保存草稿 →「校验并发布」（第 8 章）。

## ⚠️ 常见坑

- **未配置 LLM**：「设置 → LLM」没配 Provider/Model/Base URL/API Key 时，生成会直接报错——先配好并点「测试连通」；
- **描述太短**：一句话只生成 1～2 个对象。把核心实体、字段、关系都说清楚，生成质量才好；
- **生成是草稿**：别以为点完就发布了；草稿状态的本体不能导入实例；
- 质量不满意可**改描述重新生成**，或切「文档逆向」（第 5 章）喂一份更完整的文档。
