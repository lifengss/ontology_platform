# 按本体清单建立本体

> 学习目标：能在「建模」页创建本体，并按本体清单完成对象、属性、关系三步，保存为草稿。

## 1. 创建本体

1. 左侧导航 → **建模**
2. 左侧为**本体列表**：每个本体显示名称、状态徽标（草稿 / 已发布）、本体 ID 与对象数；上方有 全部 / 已发布 / 草稿 过滤
3. 点本体列表右上**＋ 新建**，右侧出现编辑区，输入名称（建议与业务域一致，如「成本核算模型」）与版本、描述

![建模页：本体列表与新建](assets/modeling-list.png "建模页：左侧本体列表，右侧编辑区")

## 2. 对象类

点**＋ 新建**后，右侧编辑区默认是**表单建模**模式（另有「AI 生成」「文档逆向」两个入口），每个对象是一张卡片：

1. 卡片头部填**对象 ID**（英文，如 `obj_customer`）、**对象名称**（中文）、**上级对象（父类）**、描述；点**＋ 添加对象**继续加
2. **主键自动确定**：第一个「必填 + string」属性自动作为业务主键（stable_key），行内出现 🔑 主键 徽标；属性顺序有意义，用行内 ↑↓ 调整（无必填 string 属性时退化为第一个 string 属性）
3. 填好描述——后续 AI 语义映射依赖它

![建模表单：对象卡片与属性表](assets/modeling-form.png "对象卡片（含 🔑 主键标记）、属性表与关系区")

## 3. 属性

对象卡片的**属性**区，点**＋ 添加属性**逐条录入：

| 列 | 说明 |
|---|---|
| 属性 ID | 英文字段名（后续导入的字段映射按它对应，如 `attr_unit_cost`） |
| 名称 | 中文名 |
| 类型 | `string` / `integer` / `float` / `boolean` / `date` |
| 必填 | 勾选后参与主键判定（必填 + string 优先作主键） |
| 约束 | 点「约束」展开：长度 / 正则 / 取值范围 / 枚举值（详见第 4 章） |

> 属性要**逐条**对照本体清单录入，属性 ID 与清单字段保持一致，后续导入的字段映射会用到。

## 4. 关系

对象卡片的**关系**区，点**＋ 关系**逐条录入：

| 列 | 说明 |
|---|---|
| 关系 ID | 英文/下划线，如 `uses` |
| 显示名称 | 中文，如「使用」 |
| 目标对象 ID | 下拉自动补全（须是本表单内已定义的对象） |
| 基数 | `1:1` / `1:N` / `N:1` / `N:N`（多对多） |

多对多关系选 **`N:N`**（平台用隐藏中间对象类承载，RDF 存储要求）。例：产品 —使用→ 材料（`N:N`）。

## 5. 保存

- 点编辑区顶部**保存**（或表单底部**保存本体**）；此时本体还是**草稿**状态
- 保存前平台会做本地预检（父级对象是否存在、ID 是否重复、约束取值是否合法），后端仍会做权威校验
- 保存成功后回到本体列表，点该本体查看/校验/发布（下一步见第 5 章）

> ⚠️ 高频坑：主键看 🔑 徽标位置——想换主键就调整属性顺序（↑↓）或改必填/类型，保存后刷新列表确认对象数符合预期。
