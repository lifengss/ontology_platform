# 校验并发布本体

> 学习目标：能校验本体并发布，理解「已发布」与「草稿」的区别，以及未发布对导入 / 查询的影响。

## 1. 校验

1. 在建模页左侧本体列表点该本体，右侧出现详情区（编辑 / 发布 / 校验 / 导出 TTL 按钮）
2. 点**校验**：系统做结构性检查（对象 / 属性 / 关系完整性、主键、约束等），结果逐条列在详情区下方
3. 有错误——点**编辑**进入表单修正，保存后重新校验，直到通过

## 2. 发布

1. 校验通过后点**发布**
2. 左侧本体列表中该本体的状态徽标变为**已发布**（过滤 tab 切「已发布」可见）

![已发布本体徽标](assets/ontology-published.png "本体列表中「已发布」状态徽标")

## 3. 「已发布」管什么

| 能力 | 需要的状态 |
|---|---|
| 实例导入（文件 / JSON / 连接） | **已发布** |
| 图谱页实例查询 | **已发布** |
| MCP 发布与 AI 查询 | **已发布** |

> ⚠️ 「导入页选不到本体 / 导入报错」几乎都是状态问题：本体还是草稿。先发布，再导入。

## 4. 发布后还能改吗

- 可以。发布后继续修改并保存，本体仍是已发布状态（草稿内容以最新保存为准）
- 重大结构变更（删对象 / 改主键）建议先在测试项目验证
