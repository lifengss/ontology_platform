# 准备工作

> 学习目标：能正确访问平台、选择部门与项目，并确认后续操作所在的数据上下文。

## 1. 访问平台

1. 浏览器打开前端：`http://<服务器地址>:8123/`
2. 看顶部**健康状态**：绿色「后端健康」表示后端（端口 8000）正常；「降级运行」（琥珀色）表示可选依赖不可用，「后端不可达」（红色）则先确认后端已启动

## 2. 选择部门与项目

1. 顶部栏有两个下拉：**部门** 和 **项目**
2. 先选部门，项目下拉会自动加载该部门下的项目
3. 后续所有操作（本体、实例、MCP）都在**当前选中项目**的上下文里进行

![平台顶栏：部门与项目选择](assets/home.png "顶栏：部门/项目下拉与健康状态徽标")

> ⚠️ 数据按「部门 → 项目」隔离：切换项目等于换了一套本体与实例。操作时「找不到本体」，先检查项目是否选对。

## 3. 准备物料

建本体前需要的材料：

| 材料 | 形式 | 必需 |
|---|---|---|
| 本体清单（对象 / 属性 / 关系清单） | xlsx / xls / csv 或文本 | 是 |
| 实例数据（后续导入用） | xlsx / xls / csv / JSON | 可后补 |
| LLM 配置（AI 辅助归一 / 自然语言查询用） | 「设置」页配置 | 可选 |

## 本章自检

- [ ] 健康状态徽标为绿色
- [ ] 已选对部门与项目
- [ ] 手上已有本体清单材料
