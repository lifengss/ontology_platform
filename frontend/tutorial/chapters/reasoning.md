# 推理视图

> **学习目标**：区分平台上两类「推理」——**业务影响推演**（改一个值会波及谁）与**本体语义推理**（OWL2-RL 补全）；V2.0 起语义推理支持 **local / Fuseki 双引擎**切换与自动降级。

## 1. 业务影响推演（R1/R2）

- **R1 回溯**：选中一个属性值，看它**由哪些上游实例/字段推出来**（沿关系回溯）；
- **R2 时间链**：按时间维度看某实体的状态演化链；
- 用途：变更前的影响面评估、故障定位（「这个数为什么是它」）。

## 2. 本体语义推理（OWL2-RL）

- 对已入库实例做 OWL2-RL 规则补全（如子类继承、属性传递）；
- 推理链路可追踪（MCP 侧对应 `inference_trace` 工具，第 16 章）。

## 3. 推理引擎双模式（V2.0）

| 引擎 | 说明 |
|---|---|
| **local（默认）** | 平台内置 rdflib 推理，零外部依赖、开箱即用 |
| **Fuseki（远程）** | 连接外部 Apache Jena Fuseki：数据推送到远程命名图，**推理闭包由平台推理核心计算**（与 local 同一闭包集，两模式输出一致），结果**写回 Fuseki 物化**——外部系统可直接 SPARQL 查推理结论 |

- **切换**：推理页「推理引擎」卡片 / `PUT /api/reasoning/engine`，运行时即时生效；
- **自动降级**：Fuseki 不可达/更新失败/读回验证失败等 5 类原因 → 自动降级 local，响应带 `degraded=true` + 中文原因提示（前端显示降级横幅）；
- **图范围**：推理图 = 本地命名图，**源连接型实例的非键内容不进推理图**（与数据边界一致）；
- 定位说明：Fuseki 模式的价值在**集中存储与共享查询**（多系统查同一推理库），时延高于 local（实测 local 中位 ~0.3s / Fuseki ~20s，如实记录、不追求远程更快）。

## ⚠️ 常见坑

- 推理页查不到东西 → 先确认实例已入库且本体已发布（第 9、10 章）；
- 语义推理结果与预期不符 → 展开 `inference_trace` 看每步规则推导，别猜；
- Fuseki 模式报 `degraded=true` → 看降级原因码（不可达/更新失败/查询失败/超时/读回不一致），恢复 Fuseki 后无需重启、下次请求自动回切。
