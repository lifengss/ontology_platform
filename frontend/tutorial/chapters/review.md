# 数据审核与实例浏览

> **学习目标**：审核导入产生的候选（批准入库/编辑/驳回/批量），入库后在实例列表与对象视图里浏览。审核是平台的**数据质量门**——LLM/映射输出禁止直落库，必须过人工确认 + SHACL 校验。

![候选审核](assets/candidates-review.png)
*候选审核区：按属性渲染的候选表格，行操作 批准入库/编辑/驳回，支持批量*

## 1. 候选与状态机

导入（第 9 章）生成的候选默认「待审核」：

```
待审核 --批准(校验通过)--> 已入库
待审核 --驳回--> 已驳回 --恢复--> 待审核
已驳回 --删除-->（仅已驳回可删）
```

> ⚠️ **待审核条目不允许直接删除**（403 FORBIDDEN_WRITE），必须先驳回再删。

## 2. 候选审核操作

- 候选以**表单化表格**展示（按对象属性渲染，不是一堆 JSON）；
- 行操作：
  - **批准入库**：再过一道 SHACL 校验，通过即入库，违规会列出违例字段；
  - **编辑**：入库前最后修正（改属性值/关系主键）；
  - **驳回**：标记不合格，可恢复回待审核或直接删除；
- **批量操作**：勾选多条 → 批量批准 / 批量驳回；「批量恢复待审核」仅对已驳回生效；
- 大批量（如 1372 条）：支持批量通过就整组过，否则拆小批。

## 3. 入库后：实例浏览

- **实例导入页**：选中对象后右侧直接显示该对象全部实例列表（无需再点）；
- **对象视图 / 全部实例**：按对象筛选、查看详情、分页；
- 入库实例**不可变**：要改数据 = 导入修正版新实例，旧的留痕。

![实例列表](assets/instance-list.png)
*实例列表：已入库实例按对象筛选展示，可查看详情*

## ⚠️ 常见坑

- **待审核不能直接删**：先驳回（见上）；
- **入库即不可变**：页面没有「编辑已入库实例」入口，是设计如此（审计留痕）；
- 批准入库失败看 violations：通常是约束（第 7 章）没过，改候选值再批。
