# 数据审核

> 学习目标：能在待审列表中逐条 / 批量审核候选实例（确认入库或驳回），理解「待审 → 已入库」状态流转与撤销机制。

## 1. 进入待审列表

1. 左侧导航 → **实例导入**
2. 右侧切到**「导入与审核」**tab（tab 上带待审数量徽标），**状态筛选**选「待审核」
3. 列表列：候选 ID / 对象 / 实例数 / 来源 / 状态（**待审核** 徽标）/ 行操作；底部显示候选总条数

![候选审核](assets/candidates-review.png "候选审核：状态筛选、批量操作按钮、待审核行与行内操作")

## 2. 逐条审核

行内操作按钮（随状态变化）：

- **批准入库**：通过并入库（写入 Neo4j + RDF 双写）
- **编辑**：打开「审核候选实例」弹窗，修改字段值后保存修改（改错值、补漏值）
- **驳回**：丢弃该候选

## 3. 批量审核

1. 勾选左侧多选框（多行；不勾选则对当前筛选范围内全部候选生效）
2. 点候选审核区顶部的批量按钮：**批量批准** / **批量驳回** / **批量恢复待审核** / **批量删除**
3. 批准后候选状态变为**已入库**，可在状态筛选中切换查看

> 批量操作只对本项目内可见的候选生效。

## 4. 撤销与修正

- **已驳回**的候选：行内**恢复待审核**（或批量「批量恢复待审核」）退回待审重新处理
- **已入库**的候选：行内**查看**（只读弹窗）核对字段值；确认有误时**删除**候选（批量「批量删除」同样适用）后重新导入

> ⚠️ 高频坑：看到「导入成功」就以为数据已入库。实际数据在**待审**列表里——**确认**之后才进图谱、才被 AI 查询。忘了审核 = 数据「隐身」。
