# 导入实例数据

> 学习目标：能用文件上传、粘贴记录两种主方式把实例数据导入平台（外部系统经 MCP 连接读取为扩展方式），并理解导入结果的去向（待审）。

## 1. 文件上传（最常用）

1. 左侧导航 → **实例导入**
2. 左上**选择本体**下拉选目标本体（只显示**已发布**的本体），左侧实体树出现该本体的对象
3. 左侧树中选中目标对象，右侧**对象视图**的「导入 / 添加实例」区出现两个入口：
   - **① Excel / CSV 文件导入**：上传 `.xlsx` / `.csv` → 点**上传生成候选**（表头建议与属性 ID 一致，未匹配列会被忽略；可先**下载模板**）
   - **② 多对象批量导入**（切到右侧「导入与审核」tab）：上传 `.xlsx` 多 sheet / `.csv` → 点**批量上传（多对象）**，按 sheet 名自动匹配对象，无需逐个选对象

导入自动走这条链路（无需人工干预）：

1. 解析文件，得到字段映射（LLM 辅助或表头匹配）
2. 生成**候选实例**——进入待审列表，**尚未入库**
3. 页面出现导入结果提示（成功 / 失败条数）

## 2. 粘贴记录（字段映射 / LLM 文本抽取）

在**对象视图**的「导入 / 添加实例」区（先选中对象）：

1. 选**字段映射**：填「字段映射 JSON」（源字段 → 属性 ID）+「源记录 JSON 数组」，如 `[{"外币类型": "美元", "汇率": 7.0}]`
2. 或选 **LLM 文本抽取**：填 LLM Endpoint / 模型，粘贴待抽取文本
3. 点 **Preview** 生成候选（同样进待审列表）

## 3. MCP 连接读取（扩展）

外部业务系统提供 MCP Server 时：在**MCP 页**「外部 MCP 数据源连接（入）」配置连接（端点 / 鉴权 / 映射到本体 / 工具白名单，见第 9 章），点连接的**读取**——系统调用其工具生成候选，再到「实例导入」审批。

> ⚠️ **导入 ≠ 入库**：所有导入结果都先进**待审**列表，审核确认（第 7 章）后才写入正式实例。「导入成功」提示指的是「候选已生成」，不是「数据已保存」——图谱和 AI 查询此刻还看不到这批数据。
