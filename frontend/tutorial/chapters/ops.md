# 登录鉴权、用户与设置

> **学习目标**：会用设置页完成**登录**、建用户（4 角色 RBAC）、建项目；知道 LLM 连接与 Prompt 模板在哪配、依赖 LLM 的功能有哪些；会用日志页排障。

## 1. 登录与鉴权（V2.0 起）

- 设置页 →「登录」：账号 + 密码。初始管理员 **`admin`**；
- 初始密码来源：环境变量 **`ONTOLOGY_BOOTSTRAP_ADMIN_PASSWORD`**（新版已废弃明文密码文件；旧库内哈希重启后仍有效）；
- 登录后右上角显示**当前用户 + 权限矩阵**（角色/租户/资源授权）概况；
- 脚本侧：`POST /api/auth/login?mode=bearer` → `data.token`，后续 `/api/*` 带 `Authorization: Bearer <token>`。

> ⚠️ 脚本/Agent 侧一律用 `http://127.0.0.1:8000`——Windows 上 `localhost` 会解析到 IPv6 `::1` 导致请求挂起。

![登录](assets/v2-login.png)
*设置页 → 登录：初始管理员 admin，登录后显示当前用户与权限矩阵*

## 2. 用户管理（4 角色 RBAC）

- 设置页 →「用户管理」→ 新增用户：**账号 / 密码（≥8 位）/ 角色 / 部门归属**；
- 角色四级：

| 角色 | 权限 | 典型场景 |
|---|---|---|
| `admin` 管理员 | 全部（含用户/项目管理） | 平台管理员 |
| `modeler` 建模人 | 可读可写（建模/导实例/建能力） | 日常建模用户 |
| `reviewer` 审核人 | 读 + 审核入库 | 数据审核岗 |
| `viewer` 查看人 | 只读 | 业务查看 |

- **权限变更免重登即时生效**（改角色/授权后用户下一次操作即按新权限）；
- 部门/租户隔离：数据共享四级，**实例数据绝不跨租户共享**（INV-2）。

![用户管理](assets/v2-users.png)
*用户管理：新增用户（账号/角色/部门），归属租户 default*

## 3. 项目管理

- 新建/重命名/删除项目（项目归属部门，作为租户边界承载本体/实例/能力）；
- 首页项目卡显示名称/部门/状态/数据量统计；
- 所有数据接口按 `?project_id=` 隔离（第 2 章）。

![项目](assets/v2-project.png)
*新建项目：名称 + 部门 + 描述*

## 4. LLM 连接与 Prompt 模板

- 设置页配 LLM（endpoint/key/模型）；4 个 Prompt 模板（自然语言建模/文本抽取/文档逆向/自然语言查询）可自定义；
- **依赖 LLM 的功能**：自然语言建模（第 4 章）、LLM 文本抽取（第 9 章）、文档逆向（第 5 章）、自然语言查询（第 12 章）、能力 AI 生成（第 15 章）——LLM 没配好时这些功能都会直接报错。

## 5. 日志与审计

- 日志页：后端 JSON 日志（级别/关键字过滤）+ 前端本地日志；
- **完整审计（V2.0）**：登录/建模/导入/审核/发布/能力执行/动作写回全留痕、**不可篡改**（INV-4）——排障与合规回查都从这进。
