# 日志与设置

> **学习目标**：会用「日志」页排查后端/前端问题，会用「设置」页配置 LLM 连接与 4 个 Prompt 模板、管理项目。

## 1. 日志页

![日志页](assets/logs-page.png)
*日志页：后端日志/本地日志切换，级别过滤 + 内容关键字过滤*

- **后端日志**：拉取后端 JSON 日志（`/api/logs?days=&limit=`），每条含时间/级别/来源；
- **本地日志**：前端浏览器侧的操作日志（localStorage）；
- 支持**级别过滤**（INFO/WARNING/ERROR…）与**内容关键字过滤**，排障时先按 ERROR 过滤。

## 2. 设置页：LLM 子页签

![设置页](assets/settings-page.png)
*设置页 LLM 子页签：Provider/Model/Base URL/API Key/采样参数 + 保存设置/测试连通，下方 4 个 Prompt 模板*

| 字段 | 说明 |
|---|---|
| Provider | `OpenAI 兼容` / `openai` / `azure` |
| Model | 模型 id（如 `deepseek-v4-flash`） |
| Base URL | 端点（如 `https://api.icompify.com/v1`） |
| API Key | 保持不变表示不修改；已有 key 默认以 ······· 回显（密码框），点 👁 眼睛图标显示明文 |
| Temperature / Timeout / Max Tokens | 采样与超时参数 |
| 保存设置 / 测试连通 | 保存后点「测试连通」验证端点可用 |

**依赖 LLM 的功能**：自然语言建模（第 4 章）、LLM 文本抽取（第 9 章）、文档逆向（第 5 章）、自然语言查询（第 12 章）——LLM 没配好时这些功能都会直接报错。

**Prompt 模板（4 个，可编辑）**：

| 模板 | 作用 |
|---|---|
| 本体生成 | 自然语言建模的输出质量（对象/属性/关系怎么生成） |
| 实例抽取 | LLM 文本抽取的候选质量 |
| 文档逆向 | 文档解析成本体的 prompt |
| 知识图谱 | 自然语言查询生成查询的 prompt |

> 改模板后直接重跑对应功能验证效果即可（不必「测试连通」，那是测端点）。

## 3. 设置页：项目子页签

- 新建/重命名/删除项目（部门与项目隔离，见第 2 章）；
- 默认项目自动创建；删除项目前确认无在用的本体/实例。

## ⚠️ 常见坑

- **API Key 是机密**：不要截图发群、不要提交 git（后端侧有环境变量配置方式，界面显示「已配置（环境变量）」徽标）；
- 改了 LLM 设置**记得点「保存设置」**，只填不存不生效。
