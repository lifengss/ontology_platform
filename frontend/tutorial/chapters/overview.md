# 全流程总览

> 学习目标：理解本体平台的端到端主线——「建本体 → 导数据 → 审数据 → 看图谱 → 发 MCP → AI 调用」，并知道每步对应哪个页面。

本体平台按下面这条主线，把业务文档变成 AI 可以查询的本体：

1. **建立本体**：在「建模」页按本体清单（对象清单 / 属性清单 / 关系清单）建对象类、属性、关系
2. **校验并发布**：本体校验通过后发布——只有**已发布**的本体才能导入与查询
3. **导入实例**：在「实例导入」页上传 xlsx/csv（文件导入 / 多对象批量），或粘贴记录（字段映射 / LLM 抽取），外部系统可经 MCP 连接读取
4. **数据审核**：导入结果先进**待审**列表，人工确认后才正式入库
5. **查看视图**：在「图谱 / 推理 / 业务动作」页看实例图谱、推理结果与业务动作，支持自然语言查询
6. **发布 MCP**：在「MCP」页生成 token，把本体发布为 MCP 服务
7. **AI 调用**：在 WorkBuddy 等 AI 平台注册 MCP，直接调用本体查询工具

平台左侧导航与各步的对应关系：

| 页面 | 作用 | 对应主线步骤 |
|---|---|---|
| 首页 | 部门 / 项目切换、项目总览 | 准备 |
| 建模 | 对象 / 属性 / 关系建模、校验发布 | 步骤 1、2 |
| 实例导入 | 文件 / JSON / 连接导入 + 审核 + 实例列表 | 步骤 3、4 |
| 图谱 | 三视图 + 自然语言查询 | 步骤 5 |
| 推理 | 推理结果查看 | 步骤 5 |
| 业务动作 | 外部系统写回动作定义 | 步骤 5 |
| MCP | token 发放、MCP 服务发布 / 吊销 | 步骤 6 |
| 日志 | 后端 JSON 日志 | 排障 |
| 设置 | LLM 连接设置 | 准备 |
| 使用教程 | 本页 | — |

> ⚠️ 全程记住两条闸门：本体必须**发布**后才能导入与查询；实例必须**审核确认**后才是有效数据。
