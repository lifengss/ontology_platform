# 附录：速查与常见坑

> 本附录汇总全流程的速查表与高频坑，供回查。

## 1. 状态机速查

| 对象 | 状态流 |
|---|---|
| 本体 | `草稿 draft` →（校验通过+发布）→ `已发布 active`；改动后需重新发布 |
| 实例候选 | `待审核` →（批准+SHACL）→ `已入库`；`待审核` →（驳回）→ `已驳回` →（恢复）→ `待审核`；`已驳回` → 可删除 |
| 实例（已入库） | **不可变**——纠正 = 重导入新实例，旧的留痕 |

## 2. 页面与功能速查

| 页 | 关键功能 |
|---|---|
| 首页 | 项目/部门/后端健康（Jena/Neo4j 状态） |
| 建模 | 表单/AI 生成/文档逆向 三入口 + 对象/属性/关系/约束 + 校验发布 |
| 实例导入 | 文件/多对象批量/LLM 抽取/MCP 连接读取 → 预览 → 候选 |
| 图谱 | 本体视图/类树/知识图谱 + 自然语言查询 |
| 推理 | 业务影响推演（R1 回溯+R2 时间链）/ OWL2-RL 语义推理 |
| 业务动作 | 动作定义与展示（MVP 写回未开发） |
| MCP | 本体发布/token 生成/4 工具/端点 `/mcp/{项目id}` |
| 日志 | 后端 JSON 日志 + 本地日志（级别/关键字过滤） |
| 设置 | LLM 连接 + 4 个 Prompt 模板 + 项目管理 |

## 3. 常见坑（Top 10）

1. **未选项目**：列表/写接口报 `403 NO_PROJECT`——右上角先选部门/项目；
2. **导入 ≠ 入库**：预览只生成「待审核」候选，必须审核批准才落库；
3. **待审核候选不能直接删**：先驳回，再删；
4. **已入库实例不可变**：`POST/PUT/DELETE` 实例返回 `403 FORBIDDEN_WRITE`，纠正靠重导入；
5. **主键自动判定**：第一个「必填 + string」属性为主键，排错位置主键会漂移（三级回退，见第 3 章）；
6. **枚举不一致**：材料枚举值与本体不一致时按本体归一，否则预览阶段 violations；
7. **约束上界太紧**：材料真值 >1 时删 `maximum 1`（见第 19 章 §3）；
8. **LLM 功能依赖设置**：AI 生成/LLM 抽取/文档逆向/自然语言查询都要求设置页 LLM 已配置并连通；
9. **MCP token 轮换后**：客户端（WorkBuddy）必须完全重启才生效；`ontology_id` 用 32 位 hex ID；
10. **发布后再导数**：改了本体（属性/约束/枚举）必须重新校验发布，新规则才生效到导入校验。

## 4. 排障入口

- 日志页按 `ERROR` 过滤后端日志（第 17 章）；
- 自然语言查询/导入失败先**展开生成的查询/violations** 看具体原因；
- 依赖异常（Jena/Neo4j）回首页看健康状态；
- MCP 接入问题 → 第 16 章排障表。
