# 附录：速查与常见坑

> 本附录汇总 V2.0 全流程的速查表与高频坑，供回查。

## 1. 状态机速查

| 对象 | 状态流 |
|---|---|
| 本体 | `草稿 draft` →（校验通过+发布）→ `已发布 active`；**active 不可直接编辑**，改版走**变更提案**（完整新模型，兼容自动升版 / 破坏走审批） |
| 能力 | `草稿 draft` →（发布）→ `已发布 active`（**锁定引用版本**）；内容变更自动 minor+1（旧版可溯源）；被引用不可删除 |
| 实例候选 | `待审核` →（批准+SHACL）→ `已入库`；`待审核` →（驳回）→ `已驳回` →（恢复）→ `待审核`；`已驳回` → 可删除 |
| 实例（已入库） | **不可变**——纠正 = 重导入新实例（旧留痕）；受控写回走 Action 风险分级门禁 |

## 3. 常见坑（Top 12）

1. **未登录/未选项目**：写接口/列表报 `403 NO_PROJECT`——先登录，右上角选部门/项目；
2. **导入 ≠ 入库**：预览只生成「待审核」候选，必须审核批准才落库；
3. **待审核候选不能直接删**：先驳回，再删；
4. **已入库实例不可变**：纠正靠重导入新实例（受控写回走 Action 门禁）；
5. **主键显式指定**：stable_key 须指向本对象已存在的 string 属性；组合维度先建合成 `code`（第 3 章）；
6. **active 本体改不了**：走变更提案，且提交**完整新模型**（第 8 章）；
7. **下游 ref 上游未发布** → `REF_NOT_RESOLVED`：先发布上游能力（第 15 章）；
8. **`binds` 无条件预求值**：可选属性内联 `if()`，不放 binds（第 15 章坑①）；
9. **空字段导入**：field_map 的 records **省略空键**，别写空字符串（SHACL 枚举/必填报错）；
10. **枚举不一致**：材料枚举值与本体不一致时按本体归一（或字典登记别名），否则预览 violations；
11. **localhost → IPv6 挂起**：脚本/Agent 一律 `http://127.0.0.1:8000`（第 18 章）；
12. **MCP 首次调用 503**：轮询重试（每 2s，1~3 次）；token 轮换后客户端完全重启（第 16 章）。

## 4. 排障入口

- 日志页按 `ERROR` 过滤后端日志（第 18 章）；审计区查操作留痕（不可篡改）；
- 自然语言查询/导入失败先**展开生成的查询/violations** 看具体原因；
- 能力执行失败看**错误码 + 溯源**（MISSING_INPUT_ATTR / REF_NOT_RESOLVED / NOT_FOUND，第 15 章）；
- 依赖异常（Jena/Neo4j/Fuseki）回首页看健康状态；推理 `degraded=true` 看降级原因（第 13 章）；
- MCP 接入问题 → 第 16 章排障表。
