# 附录：速查与常见坑

> 学习目标：记住状态流转速查表与高频坑，遇到「数据不对 / 查不到」时能按表定位。

## 1. 状态流转速查

| 实体 | 状态 | 流转动作 |
|---|---|---|
| 本体 | 草稿 → 已发布 | 校验 → 发布 |
| 实例 | 候选（待审）→ 已入库 | 审核确认 |
| MCP token | 有效 → 已吊销 | 吊销（外部调用立即 401） |

## 2. 高频坑

### 2.1 导入 ≠ 入库

所有导入结果先成为**候选**，审核确认后入库。图谱 / MCP 只认已确认数据。「导入成功」=「候选已生成」。

### 2.2 多对多要勾选

多对多关系建模时必须勾「多对多」（平台自动建隐藏中间对象类）；否则按单值存储，AI 查询只返回一个值，且无法事后纠正。

### 2.3 保存 tab 分开

建模页右上角「本体」与「业务动作」是两个 tab、**分开保存**。停在「业务动作」tab 点保存不会保存本体改动。

### 2.4 stdio MCP 不写 env（本地开发）

WorkBuddy stdio 配置的 `env` 字段是整体替换环境变量，写了会丢 `SystemRoot`，Windows 下 Python 抛 `WinError 10106`，宿主只显示「连接失败」且无日志。运行参数一律走 `args`（如 `--project <项目ID>`）；token 由桥脚本从平台 `mcp_tokens.json` 读取，不走环境变量。

## 3. 页面与功能速查

| 页面 | 核心能力 |
|---|---|
| 首页 | 部门 / 项目切换、项目总览 |
| 建模 | 本体建模、校验发布 |
| 实例导入 | 文件 / JSON / 连接导入、审核、实例列表 |
| 图谱 | 三视图 + 自然语言查询 |
| 推理 | 推理结果查看 |
| 业务动作 | 外部写回动作定义 |
| MCP | token 发放、服务发布 / 吊销 |
| 日志 | 后端 JSON 日志 |
| 设置 | LLM 连接设置 |
