# AI 平台调用

> 学习目标：能在 WorkBuddy（或任意 MCP 客户端）注册平台 MCP 服务，并从 AI 平台调用本体查询工具。

## 1. 注册（以 WorkBuddy 为例）

1. 打开 WorkBuddy 的 MCP 配置（`mcp.json`）
2. 粘贴第 9 章获取的**服务端配置**
3. 保存，重启 MCP 连接

## 2. 调用

连接成功后，在 AI 对话里直接问：

- 「成本核算模型有几个对象？」
- 「产品 P001 的单价是多少？」
- 「哪些产品使用了进口材料？」

AI 会自动选择 `ontology_query` 等工具，带 token 访问平台取数作答。

> 验证技巧：问一个**模型训练数据不可能知道**的问题（如本项目里具体实例的字段值）——能答对，才是真的连通了平台数据。

## 3. 本地 stdio 桥（可选）

本地开发也可用 stdio 桥脚本 `backend/mcp_stdio_bridge.py` 注册（项目 ID 经 `--project` 参数传入），详细配置见 `docs/MCP接入配置-方案C静态Token.md`。

## 4. 常见问题

| 现象 | 原因 |
|---|---|
| 连接失败且无日志 | stdio 配置写了 `env` 字段（见附录 2.4） |
| 调用返回 401 | token 被吊销 / 配置里 token 写错 |
| 查不到数据 | 本体未发布，或实例未审核确认 |
| 自然语言查询慢 / 无结果 | LLM 未配置（「设置」页检查） |

> ⚠️ 排障顺序先查三段状态：**本体已发布 → 实例已确认 → token 有效**，再查 LLM 配置。
