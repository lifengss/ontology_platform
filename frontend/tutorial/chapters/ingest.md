# 实例导入

> **学习目标**：把业务数据（Excel/CSV/JSON/文本）导入平台，理解「导入 ≠ 入库」：导入先做**预览校验**，生成**待审核候选**，人工审核后才真正落库。

![实例导入页](assets/ingest-page.png)
*实例导入页：顶部选对象，左侧文件导入/多对象批量/LLM 文本抽取/MCP 连接读取四个入口，右侧结果与候选区*

## 1. 入口与前置

- 实例导入页 → 顶部选中目标**对象**（本体须已发布）；
- 四种导入方式（页内子页签）：

| 方式 | 输入 | 说明 |
|---|---|---|
| **文件导入** | Excel/CSV（带表头） | 列 → 属性字段映射 |
| **多对象批量导入** | 多 sheet 的 Excel/CSV | **一个 sheet 对应一个对象**，sheet 名即对象 `id`，逐个上传 |
| **LLM 文本抽取** | 粘贴业务文本 + 选对象 | LLM 按对象约束抽候选（需配置 LLM） |
| **MCP 连接读取** | 已配置的 MCP 连接 | 从外部 MCP 数据源拉实例（连接在 MCP 页配置，见第 15 章） |

## 2. 字段映射

- 上传后平台显示列名 → 属性的**映射表**：把表格列对应到对象的属性/关系字段；
- **关系字段直接填目标实例的业务主键值**（如 `产品编码` 列填 `P001`）；
- 映射错了会在预览阶段暴露。

## 3. 预览（Preview，不入库）

- 点「预览」：平台对每条记录做**前后端双校验**（必填/类型/约束）；
- 预览通过 → 可「生成候选」；
- 预览失败 → 返回 `violations`（哪条记录、哪个字段、什么错），**当场可见**，改完重传。

## ⚠️ 常见坑

- **导入 ≠ 入库**：预览生成的是「待审核」候选，不入库；必须到审核区批准（第 10 章）；
- **主键不在文件里也可以**：代理主键（如 `IL-DOM-001`）可在生成文件时按规则拼好放进主键列；
- **宽表要先转长表**：一行横跨多列的宽表，导入前按「同一度量被维度切开 → 拆多行」转换（口诀与实例见第 19 章）；
- **空值跳过**：源表「——」空值行/列导入时跳过，别留空字符串。
