## 一、导入前必须先改本体的 5 处

不改的话会有 **1425 条实例被 SHACL 拦截**。改动都在建模页做，改完**重新发布**。

### 1. `obj_material` 物料/备件 —— 加主键属性（解决 37 条主键冲突 + 8 条 pattern）

材料里 37 个 PN 同时存在于 1100、1600 两个工厂且单价不同，PN 不能单独做主键。

| 操作 | 值 |
|---|---|
| 新增属性（**放在第 1 行**） | 属性 ID `attr_material_code`，名称 `物料编码` |
| 类型 / 必填 | string / **必填** |
| 约束 | min_length `4`、max_length `64`、pattern `^[A-Za-z0-9\-]+$` |
| 取值 | `工厂-PN`，如 `1100-V00202Y000000000` |

⚠️ **必须放在属性列表第一行**——平台的 stable_key 由后端按「第一个必填 string 属性」自动回退取值，放错行主键会漂移。

| 配套改动 | 值 |
|---|---|
| `attr_pn` 的 pattern | `^[A-Za-z0-9]+$` → **`^[A-Za-z0-9\-]+$`**（8 个 PN 含连字符，如 `YZMB-01642-103`） |
| 全局约束 `cst_u_material` | 目标属性 `attr_pn` → **`attr_material_code`**（先选作用对象 `obj_material`，再选属性） |

### 2. `obj_impl_labor_baseline` 实施人工成本基线 —— 加区域属性

海外表「实施人工成本基线（海外）」的第二维是**区域/国家**（美国、加拿大、香港…51 行），本体原设计只有客户维度。

| 操作 | 值 |
|---|---|
| 新增属性 | 属性 ID `attr_region`，名称 `区域/国家` |
| 类型 / 必填 | string / **非必填**（国内表该列留空） |
| 约束 | max_length `64` |
| 位置 | 放在 `attr_baseline_code` **之后**，不要插到第一行 |

### 3. `obj_aftersales_labor_baseline` 售后人工成本基线 —— 加区域 + 改必填 + 加枚举值

| 操作 | 值 | 原因 |
|---|---|---|
| 新增属性 | `attr_region` / `区域/国家` / string / 非必填 / max_length 64，放在第 2 行 | 海外表第二维是区域（75 行） |
| `attr_customer` 必填 | **是 → 否** | 海外 1132 条无客户值，必填会全拦 |
| `attr_product_category` 枚举 | 末尾追加 **`STR`** | 海外表第 4 个产品类别是 STR（283 条），国内表是「白盒交换机」 |

### 4. `obj_onsite_rate_baseline` 现场服务率基线 —— 去掉上界

材料真值 **AI-模组类 = 1.26**（实为单台年均服务次数，可 >1）。

> `attr_onsite_rate` 约束：`minimum 0` 保留，**删掉 `maximum 1`**。

### 5. `obj_spare_aux_baseline` 备件辅助成本基线 —— 去掉上界

材料真值 **巴西税率 = 1.02**。

> `attr_tax_rate` 约束：`minimum 0` 保留，**删掉 `maximum 1`**。

## 三、转换规则（宽表 → 长表）

| 源表 | 处理 |
|---|---|
| 管理成本基线（5×4） | 客户 × 环节 × 境内外 → 20 行长表 |
| 现场服务率基线 | 产线 × 客户/细分 × 境内外；非 SV 产线无海外值 → 只出国内行 |
| 部件故障率基线 | 部件类型 × 客户细分；AI 服务器列无细分标签 → 记为「全体」 |
| 人天成本基线 | 国家 × 实施主体 × 产品线；HPC/高端列全「——」→ 跳过 |
| 人员驻场成本 | 产线 × 工程师等级 × 12 服务商区域 → 144 行 |
| 实施人工（国内/海外） | 实施类型 × 维度 × U 数档 → 长表 |
| 售后人工（国内/海外） | U 数 × 维度 × 产品类别 × 响应级别 → 长表 |
| 备件辅助成本基线 | 16 列是**不同度量**，保持宽表不拆 |
| 主表 | 区域列合并单元格已向下填充；只取成本结果列，BOM 明细区（c21 起）不导 |

### 两处口径映射（已在生成时固化）

- **海外实施人工的 U 数档**：材料表头 `2U及以下 / 3U/4U/5U / 6U / 8U` → 映射为本体枚举 `2U及以下 / 2U高密度及3U4U5U / 4U高密度6U / 8U`。
- **实施人工（国内）第二维混装**：材料该列表头即为「产线//客户/服务内容」。客户值（阿里/百度/腾讯/字节/其他）进 `attr_customer`，其余（如 `SV/EC/白盒JHJ`、`不含硬盘背板或内存背板`、`AI（含GPU驱动安装）`）进 `attr_model`。⚠️ `attr_model` 名称是「机型」，实际承载了产线与服务内容——这是材料原表的混合列所致，如需精确表达建议后续把该属性改名为「产线/服务内容」。

### 代理主键编码规则

多个基线的 stable_key 是复合维度，材料里没有单键，统一生成 ASCII 代理键（满足 `^[A-Za-z0-9_\-]+$`）：
`IL-DOM-001`（实施人工国内）/ `IL-INTL-001`（海外）/ `AL-DOM|INTL-001`（售后人工）/ `MGT-001` / `SA-001` / `OR-001` / `PF-001` / `PD-001` / `RC-001` / `MP-DOM|INTL-001`。
物料用天然键 `工厂-PN`；差旅用国家名。
