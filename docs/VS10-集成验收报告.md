## 2. 验证方法

- **e2e（核心证据）**：`test_vs10_e2e.py` 在**单一独立项目 `vs10-e2e`** 内串联全部环节，互不污染。关键设计：
  - **同进程真实 uvicorn**（module-scope fixture，随机空闲端口，真实 socket），与 `TestClient` 共享 `app` 单例，保证 `mcp_server` 发布态与 `JsonStore` 一致；
  - **真实 MCP SDK 客户端**（`mcp.client.sse.sse_client` + `ClientSession`）经 SSE 连接 `/mcp/vs10-e2e`，真实调用 `ontology_query / inference_trace / instance_get`；
  - **mock 外部 MCP**（`tests/mock_mcp_http.py`）：提供可计数的 read/write HTTP 端点，用于「外部读取归化」与「Action 回写恰好一次」的精确断言（调用次数、payload）。
- **全量回归**：确认集成改动无回归（`modeling_translator` / `jena_adapter` / `mcp_server` 等）。
- **live 冒烟**：重启运行中的 8000 后端加载新代码后，对真实部署实例做 `/health`、SHACL 校验、MCP 发布、真实 SSE 查询、取消发布的冒烟，确认部署态与测试态一致。

### §9.1-2　归化流水线 LLM 输出必经人工审核，无直落库

- **结论**：满足。

### §9.1-3　可配置并连通一个外部 MCP Server（stdio 或 http），读取数据归化入本体
- **验证**：`test_03` 配置 `transport=http` 的外部 MCP 连接（含 Bearer 凭据引用 `${VS10_MOCK_TOKEN}`）；`/test` 连通性探测 `reachable=true & auth_ok=true`；`/read` 触发外部读取工具（mock 恰好被调用 1 次）→ 归化为 2 条候选 → 人工 approve 入库；候选 `source_type=external_mcp`、`status=imported`。
- **证据**：`test_03` 通过。
- **结论**：满足（http transport；stdio 见 §5 待增强）。

### §9.1-4　可定义并触发一个 Action 回写外部平台，每次均弹人工确认，重复触发不重复回写，有执行日志
- **验证**：`test_04` 定义 webhook Action（`confirmation=human_required`、`dry_run_supported`、幂等键 `order-{orderCode}`）：
  - **dry-run**：返回 `planned_payload`，**零外呼**（`mock.write_calls==0`）；
  - **正式触发**：仅返回 `confirmation_token`，未确认**不回写**（`mock.write_calls==0`）；
  - **人工确认**：真实回写，mock **恰好收到 1 次**且 payload 正确；
  - **重复触发**（相同输入→相同幂等键）：`idempotency_hit=true`，**不再重复回写**（`mock.write_calls` 仍为 1）；
  - **执行日志**：`GET /api/actions/{id}/logs` 可查（total=1）。
- **证据**：`test_04` 通过。
- **结论**：满足。

## 4. 验收过程中发现并修复的断链（质量记录）

e2e 采用「真实 SSE 客户端 + 真实 uvicorn」，暴露出既有 REST 单测无法发现的 3 处断链，均已修复：

| # | 断链 | 根因 | 修复 |
|---|---|---|---|
| 1 | MCP SSE 真实客户端连接即 500 | Starlette `Request` 无公开 `.send`，`handle_sse/handle_messages` 取 `request.send` 抛 `AttributeError` | `backend/mcp_server/__init__.py` 新增 `_asgi_send(request)`（优先 `scope["asgi"]["send"]`，兜底 `request._send`） |
| 2 | float 字段 SHACL 校验误杀 | pyshacl 在 `inference="none"` 下把整数形态 float 词法（`'-5'`/`'88'`，无小数点）判为非法 `xsd:float`，合法样本被误拒、违规样本多报一条 datatype 违和 | `modeling_translator` 新增权威 `typed_literal()`（float 转 Python float 保证词法含小数点），`build_instance_graph`（校验）与 `jena_adapter/rdf_sync`（物化）共用，消除两路径逻辑分叉 |
| 3 | `JSONResponse` 导入错误 | `from fastapi import JSONResponse` 不存在 | 改为 `from fastapi.responses import JSONResponse` |

> 说明：#2 的根因经对照实验精确定位——同一数据/shape 下，仅 `inference` 参数不同结果即不同（`inference="none"` 误判、默认不判）。修复后 `amount=88`（整数形态 float）`valid=True`、`amount=-5` 仅报正确的 `minInclusive` 违和（`path=amount`）。
