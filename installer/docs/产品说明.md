# 企业业务本体平台（Windows 本地安装版）

## 功能简介

企业业务本体平台：从业务文档/表格到"AI 可直接调用的业务世界模型"的本地化平台。
包含本体建模（表单/自然语言 AI/文档逆向/CSV 导入）、SHACL 约束、RDF 存储与校验、
图谱可视化（RDF/知识图谱/业务图谱）、自然语言查询、规则推理、业务动作、
MCP 接入层（可被 WorkBuddy/Claude/Cursor 等 AI 平台调用）。

## 安装

1. 双击 `OntologyPlatform-Setup-1.0.1.exe`（需管理员权限）。
2. 选择安装目录（默认 `C:\Program Files\OntologyPlatform`），下一步到底。
3. 安装器会自动完成：
   - **端口检测与重分配**：默认端口 backend 8000 / frontend 8123 / Fuseki 3030 / Neo4j 7474+7687 / Postgres 5432；
     若被占用，自动改用相邻空闲端口，并同步改写全部启动配置（前端 API 基址、Neo4j/Postgres 配置、环境变量）。
   - **依赖检测与安装**：系统已有 Java 21+ / Python 3.10（含 pip）则直接复用（跳过捆绑安装）；
     否则自动安装捆绑的 JDK 21 / Python 3.10（离线 wheel 库，无需联网）。
   - 初始化 Postgres（ont 用户/库）、Neo4j（初始密码）、RDF 数据集目录。
4. 安装日志：`<安装目录>\logs\install.log`；实际端口与配置：`<安装目录>\scripts\runtime-config.json`。

> 自包含说明：安装包内置 JDK 21、Python 3.10（离线 wheelhouse）、Apache Jena Fuseki 5.1.0、
> Neo4j Community 2026.09.0、PostgreSQL 16.4，安装与运行全程无需联网。

## 启动 / 停止

- 桌面快捷方式：**本体平台-启动** / **本体平台-停止**（或安装目录下 `start-platform.bat` / `stop-platform.bat`）。
- 启动后浏览器打开 `http://localhost:<前端端口>`（见 runtime-config.json）。
- 首次启动 Neo4j 较慢（约 1-3 分钟），属正常。

## 目录结构（安装目录）

| 路径 | 说明 |
|---|---|
| `frontend\` | 前端（使用教程在平台内「使用教程」页，共 20 章） |
| `backend\` | 后端 FastAPI 源码 |
| `backend\data\` | 运行时数据（RDF 数据集/本体/实例/日志配置）——备份此目录即备份全部业务数据 |
| `deps\` | 本地依赖服务（Fuseki/Neo4j/Postgres/JDK） |
| `runtime\` | Python 环境与捆绑运行时包 |
| `scripts\` | 启动/停止脚本与运行时配置 |
| `logs\` | 安装与运行日志 |

## 卸载

控制面板卸载（或 `Uninstall.exe`）：自动停止服务、删除桌面快捷方式并移除安装目录。
**卸载会删除 `backend\data\` 中的全部业务数据，请先备份。**

## 常见问题

- **启动报"端口仍被占用"**：其他程序占用了配置端口。关闭占用程序，或重新运行安装器
  （`scripts\install-deps.ps1`，管理员）重新自动分配。
- **AI 能力（自然语言建模等）不可用**：默认 LLM 端点未配置。进入平台「日志与设置」
  页配置 OpenAI 兼容端点（或本地 Ollama `http://localhost:11434/v1`）。
- **MCP 接入端口**：MCP stdio 桥默认连本机后端端口，安装器已同步改写
  `backend\mcp_stdio_bridge*.py`，与 runtime-config.json 一致。
