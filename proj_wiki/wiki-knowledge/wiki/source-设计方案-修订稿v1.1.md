# 源摘要：MVP 阶段设计方案（修订稿 v1.1）

> 原始文件：`raw/设计方案-修订稿v1.1.md`（不可变）。本文为 LLM 提炼摘要。

## 文档性质
技术方案基线。在 v1.0 定稿版基础上，将"通过 MCP 读取外部含鉴权数据平台"与"本体 Action 对外部平台回写"从 V2.0 前置纳入 MVP，并据用户三项决策修订。

## 核心变更（v1.0 → v1.1）
- **C1 MCP 能力**：由仅 Server 端扩展为**双向**（Client 端接入外部数据平台）。
- **C2 Action**：由仅元数据扩展为**受控执行**（人工确认 + 幂等 + 日志）+ 回写。
- **C3 外部接入**：新增"外部 MCP 数据源"为一等接入方式（带鉴权）。
- **C4 技术表述**：修正"开源不支持 MCP"——复用官方 [[MCP双向能力|MCP Python SDK]]。
- **C5/C6/C7**：风险清单调整；新增"平台自身不鉴权、鉴权交外部""回写每次确认"决策。

## 架构要点
- 七层架构裁剪（L1 数据接入 / L2 建模 / L3 存储 / L4 推理 / L5 消费 / L6 应用 / L0 治理）。
- [[双层建模架构]]：业务层（ITBP 可见）屏蔽 OWL 术语，标准层映射 OWL2-RL + SHACL。
- [[混合存储]]：Jena（TBox/推理，独立 HTTP）+ Neo4j（ABox）+ pgvector（向量）。
- [[MCP双向能力]]：Server 端由本体 Schema 自动生成工具；Client 端接入外部源。
- [[外部数据源MCP接入]]：连接配置 / 鉴权 / 读取映射 / 健壮性。
- [[Action受控回写]]：受控执行引擎与安全护栏。
