# 实例导入与审核

> 页面原名“归化”，意为 Instance Canonicalization。2026-10-20 改为“实例导入与审核”。
> 核心铁律：LLM/字段映射输出**禁止直落库**，必须经过 preview → candidate → 人工审核 → SHACL → 入库。

## 页面功能

1. 左侧：选择本体，查看对象列表，点击对象查看其属性/关系/约束。
2. 右上：生成候选 Preview（支持字段映射 / LLM 文本抽取两种来源）。
3. 右中：对象约束面板（只读 / 编辑态），可就地修改对象的属性、关系。
4. 下方：候选审核列表，点击候选进入表格化审核弹窗。

## 数据来源切换

- **字段映射**：JSON 数组 → 字段映射 → 候选实例。
- **LLM 文本抽取**：粘贴业务文档 → LLM 按对象约束抽取候选实例。

## 强制约束校验

Preview 阶段前后端双校验：
- 前端：`validateRecordAgainstOntology()` 检查必填、类型（integer/float/boolean/date/string）。
- 后端：`ingestion/__init__.py` 中 `_validate_record_against_object()` 重复校验，`_coerce_value()` 强制类型转换。
- 任一记录不合规即 422，并返回 violations 列表。

## 对象约束就地编辑

- 按钮：对象约束面板右上角“编辑”。
- 操作：修改对象名称、描述；增删改属性（ID/名称/类型/必填）；增删改关系（ID/名称/目标对象/基数）。
- 保存：调用 `PATCH /api/ontologies/{id}/objects/{object_id}`，成功后刷新本体列表与字段映射建议。

## 候选审核表格化

- 不再展示 JSON 数组。
- 按目标对象的每个属性/关系生成表单输入框：字符串、数字、日期、布尔下拉、关系目标主键。
- 保存时自动类型转换并提交。
