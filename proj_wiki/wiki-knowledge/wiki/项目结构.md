# 项目结构（运行时视角）

> 本地网页服务形态：FastAPI 后端 + 原生 HTML/JS 前端，数据默认落地本地 JSONL/JSON/TTL，可选 Jena/Neo4j/Postgres。

```
d:/self_coding/ontology_platform/
├── backend/                    # FastAPI Python 后端
│   ├── main.py                 # 应用入口、health、全局异常、MCP 挂载
│   ├── api/                    # FastAPI 路由
│   │   ├── router_ontologies.py    # 本体 CRUD、PATCH 对象、LLM from-text
│   │   ├── router_ingest.py        # 候选 preview/approve/review、实例查询
│   │   ├── router_llm.py           # LLM 设置、提示词模板
│   │   ├── router_system.py        # 日志、客户端日志上报、健康相关
│   │   └── ...
│   ├── ingestion/__init__.py   # 实例归化核心：preview / approve / SHACL / 强制约束校验
│   ├── modeling_translator.py  # 业务层↔OWL/SHACL 翻译
│   ├── jena_adapter/client.py  # Fuseki HTTP 封装、SHACL、TTL 本地降级
│   ├── neo4j_sync/__init__.py  # Neo4j 写入 / 文件降级
│   ├── schemas/                # Pydantic 模型（部分未完全启用）
│   ├── stores/                 # JsonStore 本地存储
│   ├── logging_setup.py        # 结构化日志
│   └── data/                   # 运行时数据（JSONL/JSON/TTL）
├── frontend/                   # 原生 HTML/JS 前端
│   ├── index.html              # 单页应用 HTML
│   ├── app.js                  # 全部页面逻辑（约 4000+ 行）
│   └── style.css               # 样式
├── scripts/                    # 调试/验证脚本
├── deploy/                     # Dockerfile
├── docker-compose.yml          # 完整基座编排（Jena/Neo4j/Postgres）
└── proj_wiki/wiki-knowledge/   # 项目 Wiki（本目录）
```

## 后端关键文件说明

| 文件 | 职责 |
|---|---|
| `main.py` | 应用入口；挂载 MCP；`/health` 依赖探测；全局异常与日志中间件 |
| `api/router_ontologies.py` | 本体 CRUD；`PATCH /api/ontologies/{id}/objects/{obj_id}` 对象轻量更新 |
| `api/router_ingest.py` | `preview`、`approve`、候选实例增删改、已入库实例查询 |
| `api/router_llm.py` | LLM 设置读写、环境变量提示 |
| `ingestion/__init__.py` | 归化核心：`preview()` / `approve()`；`_validate_record_against_object()` 强制约束校验；`_coerce_value()` 类型转换 |
| `jena_adapter/client.py` | Fuseki HTTP 调用；SHACL；不可达时降级本地 TTL |
| `neo4j_sync/__init__.py` | Neo4j 节点/关系写入；不可达时降级本地 JSONL |
| `modeling_translator.py` | 业务层对象/属性/关系 → OWL2-RL + SHACL |
| `stores/json_store.py` | JsonStore：本地 JSON/JSONL 持久化 |

## 本机启动（MVP 默认，不依赖 Docker，依赖自包含）

MVP 默认从本机启动，依赖地址改为 localhost。所有第三方依赖应内嵌到 `deps/` 目录，便于后续封装安装包时自包含、无需联网。

| 依赖 | 项目内路径 | 状态 |
|---|---|---|
| Jena/Fuseki | `deps/apache-jena-fuseki-5.1.0/` | 已内嵌 |
| PostgreSQL + pgvector | `deps/pgsql/` | 已内嵌 |
| Neo4j Community | `deps/neo4j-community-5.20.0-windows.zip` → 解压到 `deps/neo4j-community-5.20.0/` | zip 损坏，需替换完整包 |

一键启动脚本（优先使用 `deps/` 内依赖）：
```powershell
# 启动后端 + 依赖（Jena/Neo4j/Postgres）
.\scripts\start_mvp_local.ps1

# 只启动后端（依赖自行提前运行）
.\scripts\start_mvp_local.ps1 -StartBackendOnly

# 跳过部分依赖
.\scripts\start_mvp_local.ps1 -SkipNeo4j -SkipPostgres
```

如需 Docker Compose（非 MVP 默认）：
```bash
docker compose up -d
```

### 依赖包准备（用于封装安装包）

封包前请把完整依赖放入 `deps/`：
1. **Jena**：下载 `apache-jena-fuseki-5.1.0.zip`，解压到 `deps/apache-jena-fuseki-5.1.0/`
2. **PostgreSQL**：下载带 pgvector 的 Windows 二进制包，放到 `deps/pgsql/`
3. **Neo4j**：下载 `neo4j-community-5.20.0-windows.zip`（约 130MB+），放到 `deps/neo4j-community-5.20.0-windows.zip`；启动脚本会自动解压到 `deps/neo4j-community-5.20.0/`

当前环境因网络限制无法下载 Neo4j，需手动替换 `deps/neo4j-community-5.20.0-windows.zip`。

## 运行时数据目录

- `backend/data/`：本体 JSON、候选 JSON、实例 JSONL、TTL 文件等
- `backend/secrets/`：LLM API key 等敏感配置
- `backend/logs/`：结构化日志文件

## 降级策略

当依赖服务未启动时：
- Jena 不可达 → SHACL/OWL 降级为结构校验；保存为本地 TTL
- Neo4j 不可达 → 实例写入本地 JSONL
- Postgres 不可达 → 向量索引不可用（不影响核心功能）

健康检查 `/health` 返回 `degraded` 属正常，页面显示为“降级运行”。
