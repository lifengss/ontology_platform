# 项目概览：企业业务本体平台（MVP）

企业业务本体平台是公司内部 40+ 部门用于搭建**业务本体**的工具，目标是为大模型 Agent 提供**语义底座**，约束其数据使用逻辑、降低幻觉。当前处在 **MVP（本地单人模式）** 阶段，核心假设是"用本体约束后 Agent 错误率显著下降"，MVP 优先快速验证该假设而非功能完备。

## 一句话定位
> 不做业务系统，只做"让 Agent 用对数据、说对话"的语义约束层；MVP 形态为**本地网页服务**，并通过 **MCP 双向**打通外部数据平台（读 + 受控回写）。

## 关键事实（已确认决策）
- **软件形态**：本地网页服务（FastAPI 后端 + 浏览器前端，Jena/Neo4j/Postgres 同机，Docker Compose 一键起）。见 [[软件形态与部署]]。
- **MCP 双向**：对外发布 MCP Server（本体查询/推理工具）；对内作为 MCP Client 接入外部含鉴权数据平台。见 [[MCP双向能力]]、[[外部数据源MCP接入]]。
- **外部 MCP Server 已存在**（对接方提供），平台只消费、不假设自建。
- **Action 受控回写**：每次执行均需人工确认，MVP 不做自动回写。见 [[Action受控回写]]。
- **平台自身不鉴权**：Demo 不实现登录层，鉴权交由外部数据平台；外部凭据本地 env/配置管理。
