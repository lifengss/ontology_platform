# 实例归化流水线

把源数据自动转换为本体实例并入库的流水线，核心铁律是**人工审核卡点**（对应优化 5）。

## 流程
源数据（文档 / 数据表 / **外部 MCP 读取结果**）→ LLM 或字段映射生成**候选实例** → **人工审核 UI** → 审核通过写入本体实例库。

## 硬约束
- **LLM 输出禁止直接落库**：否则产生大量脏实例，直接破坏本体"解决幻觉"的目标。
- 支持自定义 LLM endpoint。
- 外部 MCP 读取的结构化数据可信度高于 LLM 自由生成，可走「字段映射 + SHACL 校验」路径；但**首次接入或映射变更须人工确认卡**。

## 数据质量背景
源系统数据质量参差、同义异写，故强制审核 + SHACL 校验 + 逆向建模二次修正。

## PRD 优先级
- P0：LLM 输出必经人工审核；可切换模型。
