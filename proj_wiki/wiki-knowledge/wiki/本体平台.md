# 本体平台（企业业务本体平台）

公司内部用于搭建**业务本体**的工具产品，定位为大模型 Agent 的**语义底座**。由各部门的 [[ITBP]] 负责搭建本部门本体并发布/接入 MCP 服务。

## 关键属性
- **当前阶段**：MVP（本地单人模式），核心目标是验证"本体约束降低 Agent 幻觉"的价值假设。
- **形态**：本地网页服务（见 [[软件形态与部署]]）。
- **不做**：业务系统开发；只做语义约束层。
- **远期**：V2 服务端（多租户/治理）、V3（BI/资产市场）。见 [[范围与版本规划]]。

## 双向 MCP 角色
- 对外 = MCP Server（被外部智能体调用，见 [[MCP双向能力]]）。
- 对内 = MCP Client（接入外部含鉴权数据平台，见 [[外部数据源MCP接入]]）。
