# 技术选型（组件清单）

MVP 复用开源组件、不自研核心语义逻辑；内部自用不排斥 GPL 强传染组件。

| 组件 | 许可 | 用途 | 备注 |
|---|---|---|---|
| WebProtégé | BSD-2-Clause | 本体建模参考 | 复用后端 API，前端自研业务友好 UI |
| Apache Jena | Apache 2.0 | OWL/SHACL/推理/SPARQL | 独立 HTTP 服务，Python 仅 HTTP 调用（见 [[混合存储]]） |
| ROBOT | BSD-3-Clause | 格式转换/一致性校验 | CI 校验 |
| LinkML | MIT/CC0 | 模板声明式管理 | — |
| Neo4j Community | GPLv3 | ABox 实例/图可视化 | 内部自用可接受；不依赖其做 OWL-DL 推理 |
| pgvector | PostgreSQL 扩展 | 向量检索 | — |
| MCP Python SDK | MIT | MCP Server+Client | 复用官方 SDK，不自研传输层（见 [[MCP双向能力]]） |
| cryptography | Apache-2.0/BSD-3 | 凭据加密（生产建议项） | Demo 可不启用 |

## 不可二次开发
GraphDB Free、Stardog Free、AnzoGraph Free —— 仅免费授权，非开源。

## 复用策略要点
- 核心语义逻辑（OWL/SHACL）复用 Jena，少手写；
- MCP 传输/协议复用官方 SDK；
- 建立测试集（含外部 MCP mock、Action dry-run）应对单人+AI 编码风险。
