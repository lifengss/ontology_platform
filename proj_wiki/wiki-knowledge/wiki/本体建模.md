# 本体建模（4 种方式）

MVP 支持的本体构建方式，均通过友好 UI 操作，底层映射 W3C OWL2-RL + SHACL（见 [[双层建模架构]]）。

## 四种建模方式
1. **手工建模**：人工定义对象/属性/关系/约束。
2. **逆向建模**：从数据库表导入 Schema（L1 数据接入之一）。
3. **Schema 约束配置**：以约束驱动建模。
4. **混合建模**：以上组合。

## 业务层语义呈现
类层次、对象/数据属性、约束在业务层以「对象/属性/关系/约束」语义呈现，平台翻译为 OWL 原语。逆向建模产出的 Schema 允许人工二次修正。

## PRD 优先级
- P0：4 种建模方式均可创建可保存模型；业务层屏蔽 OWL 术语。
