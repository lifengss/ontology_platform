# 本地一键启动

## 适用场景

MVP 阶段在 Windows 本机快速拉起整套服务，无需 Docker。

## 前置准备

1. Python 3.10+ 并安装后端依赖（`cd backend && pip install -r requirements.txt`）。
2. 项目内 `deps/` 目录已包含：
   - `apache-jena-fuseki-*`
   - `neo4j-community-*.zip`（首次启动会自动解压）
   - `pgsql/`
   - `jdk-21*/`（Neo4j 2026.x 需要 JDK 21+；脚本会自动检测并使用）

## 一键启动脚本

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_mvp_local.ps1
```

脚本位置：`scripts/start_mvp_local.ps1`

启动的服务与端口：

| 服务 | 端口 | 备注 |
|------|------|------|
| FastAPI 后端 | 8000 | http://localhost:8000 |
| Jena/Fuseki | 3030 | 可选，缺失时后端降级本地 TTL |
| Neo4j Bolt | 7687 | 初始密码 `neo4jsecret` |
| PostgreSQL | 5432 | 首次启动自动 initdb |

## 常用参数

```powershell
# 仅启动后端（依赖已在外部运行）
powershell -ExecutionPolicy Bypass -File scripts/start_mvp_local.ps1 -StartBackendOnly

# 跳过某项依赖
powershell -ExecutionPolicy Bypass -File scripts/start_mvp_local.ps1 -SkipNeo4j
powershell -ExecutionPolicy Bypass -File scripts/start_mvp_local.ps1 -SkipJena
powershell -ExecutionPolicy Bypass -File scripts/start_mvp_local.ps1 -SkipPostgres
```

## 验证健康状态

```bash
cd backend
python scripts/check_health.py
```

期望结果：

```json
{
  "status": "ok",
  "dependencies": {
    "jena": "healthy",
    "neo4j": "healthy",
    "postgres": "healthy"
  }
}
```

## 启动前端

```bash
cd frontend
python -m http.server 8080
```

访问：http://localhost:8080

## 故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| Neo4j 提示 `UnsupportedClassVersionError` | JDK 版本不足 | 脚本会自动使用 `deps/jdk-21*/`；检查该目录是否存在 |
| Postgres `could not bind address` | 5432 已被其他实例占用 | 通常本机已有 Postgres 运行，可直接复用 |
| 脚本中文乱码/语法错误 | PowerShell 5.1 默认编码非 UTF-8 | 脚本已保存为 UTF-8 BOM |
