# 混合存储

针对团队 Python 主栈、语义网理论偏弱的现状，采用混合存储（对应优化 4），需处理 Java 语义组件与 Python 服务层集成。

## 三层
1. **TBox 本体 Schema（模式层）**：Apache **Jena** 做 OWL 解析、SHACL 校验、DL 推理；以**独立 HTTP 服务**部署，Python 后端仅 HTTP 调用，避免 Java/Python 深度混编。推理与校验见 [[推理与SHACL校验]]。
2. **ABox 实例数据**：**Neo4j 社区版**做实例存储、图遍历、可视化。注意：Neo4j 社区版不提供原生 OWL-DL 推理，推理统一交给 Jena。
3. **向量索引**：**pgvector**（PostgreSQL 扩展）用于文档归化实例的向量检索。

## 许可说明
内部自用可接受 GPL 组件（Neo4j 社区版），但禁止对外分发修改版；不依赖其做 OWL-DL 推理。详见 [[技术选型]]。
