# 多租户与共享等级（V2-06 / M2-C，2026-11-11 交付）

> 需求来源：[[source-V2-功能需求描述]] V2-06；验收：[[source-V2-测试用例]] TC-06-01~08 / TCE-06-01~03；接口契约：API 文档 §24；进度：[[V2开发里程碑]] M2-C ✅。

## 一句话

**项目（project）即租户边界**；本体共享等级只作用于 **schema 只读**；**实例永不共享（INV-2）**；上传型实例内容默认仅上传者可读，可显式开放。

## 核心规则

1. **租户隔离**：project 归属 `tenant_id`（缺省 default），user 绑定 `tenant_id`（admin 跨租户）。跨租户访问项目级资源（连接/字典/候选审批等）一律 **404，不泄露存在性**（与真实不存在同文案）。
2. **四级共享（schema 只读）**：
   | 等级 | 可见范围 |
   |---|---|
   | private | 仅 owner |
   | project | shared_with 指定成员（**可跨租户**，无效账号 422） |
   | department | 本租户全员 |
   | public | 全部用户 |
   - 新建本体默认 **private**；存量无 `sharing` 字段视为 department（不收紧既有协作）。
   - 调整入口：`PATCH /api/ontologies/{id}/sharing`（仅 owner/admin），**即时生效**（降级即时收口），留 `sharing_change` 审计（from/to）。
3. **实例永不共享（INV-2）**：实例/连接/字典/候选按租户隔离；跨共享范围的用户仅可见 schema，实例列表 200 空、详情 404。
4. **上传型内容显式开放**：默认仅上传者/admin 可读；`content_open: {users, departments}` 显式开放，**上限=本体共享等级可见范围**（超出 422）；受限者见字段值置空＋显式 `content_restricted: true`（保留键/类型/关系元数据）；开放/收回留审计。
   - 端点：`POST /api/ingest/instances/{id}/content-open` / `content-revoke`（仅上传者/admin）。
5. **共享不授写**：写权限 = admin / owner / 同租户且 M2-A RBAC 允许；跨租户一律 403。
6. **源连接型内容**：按访问者身份经 [[身份联邦]] `federated_read()` 委托代查（TC-06-06 联验）。

## 实现要点

- 判定层：`backend/tenant.py`（`ensure_project_access` / `ensure_schema_visible` / `ensure_schema_write` / `content_visible` / `instance_read_allowed` / `project_tenant_guard` / `audit_content_open`）——统一口径，路由只调不重写。
- 接入：router_ontologies（sharing 端点＋schema 可见/写判定）、router_graph、router_mcp（router 级守卫）、router_dictionary（router 级守卫）、router_ingest、router_projects、router_auth；`api/dependencies.py` 的 `project_id_param` 改为**资源级判定**（不再项目级一刀切 404，避免与跨租户 schema 共享冲突）。
- 数据：ontology `owner/sharing/shared_with`；project/user `tenant_id`；instance `uploaded_by/content_open`；candidate `created_by`。
- 前端：建模页本体详情**共享等级控制**（owner/admin 可调，project 级成员输入）；实例详情弹层**内容受限提示＋开放管理**（开放/收回）。
